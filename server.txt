project_1 (폴더 구성)
ㄴ front
ㄴ server

cd server
ㄴ npm init -y      : package.json 생성
ㄴ npm i express    : 라이브러리 설치
ㄴ index.js 생성     : 코드 작성

객체를 import 하는 방법 (서버에서는 import 사용불가)
ㄴ const express = require('express')

서버 실행
ㄴ node index.js

- 서버에서는 코드를 변경해도 실시간으로 반영되지않고 서버를 재실행 해야 반영됨

실시간 업데이트 모듈
ㄴ npm i nodemon
ㄴ npx nodemon index.js   (서버 실행)

exports 하는 방법
ㄴ module.exports = todolist;

클라이언트 접근 허용 (http://)
ㄴ npm i cors                      (라이브러리 설치)
ㄴ const cors = require('cors');   (import)
ㄴ app.use(cors());                (사용)


const todolist = express.Router(); (페이지 분리)
